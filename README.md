# Flask-Todo-App

# Flask Todo App ✅

A modern Todo List web application built using Flask, SQLAlchemy, Bootstrap, HTML, CSS, and SQLite.

## Features

- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Complete
- Task Categories
- Priority Levels
- Due Dates
- Search Tasks
- Statistics Dashboard
- Progress Bar
- Responsive UI
- Modern Gradient Design

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML5
- CSS3
- Bootstrap 5

## Installation

1. Clone the repository

```bash
git clone https://github.com/maahhhiii/Flask-Todo-App.git
```

2. Navigate to project folder

```bash
cd Flask-Todo-App
```

3. Create virtual environment

```bash
python -m venv venv
```

4. Activate virtual environment

Windows:

```bash
venv\Scripts\activate
```

5. Install dependencies

```bash
pip install -r requirements.txt
```

6. Run the application

```bash
python app.py
```
